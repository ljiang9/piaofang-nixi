# 票房逆袭模拟器 piaofang-nixi

原创娱乐小游戏:扮演小成本喜剧片发行方,在 7 天国庆档里分配排片与营销预算,
靠口碑把「档期炮灰」的标签翻转为「逆袭黑马」。

## 热点来源声明

灵感来自 2026 年国庆档的真实社会现象:档期票房破 7 亿,小成本喜剧从「炮灰」
标签一路逆袭、冲上热搜第一。本项目是对「票房逆袭」这一现象的善意致敬与
玩法化演绎。

**片名《全村第一笑》、竞争对手《星河战纪3》《古城谍影》及所有人物均为纯属
虚构,与任何真实影片、演员、公司无关。** 数值与事件为游戏性设计,不代表
真实电影市场规律。

## 玩法

你是一部小成本喜剧片的发行方,开局标签:「档期炮灰」。

- **7 天国庆档**(10 月 1–7 日):每天手动分配
  - **排片占比**:0–30%(上限钳制,超了会被判定非法操作)
  - **营销费用**:从 2000 万总预算里花,花超了同样非法
- **口碑系统**:每天随机事件让口碑 ± 波动
  - 观众自来水安利 / 短视频二创病毒传播 / 影评人长文好评(涨口碑)
  - 隔壁大片点映口碑爆了 / 营销翻车(掉口碑)
  - 营销费用按边际递减转化为口碑;排片远超口碑支撑(> 口碑/3)会被观众吐槽掉口碑
- **票房公式**:当日票房 = 排片占比 × 口碑系数 × 当日大盘(7 天大盘合计约 7.15 亿)
- **标签翻转**:口碑达到 75,或单日票房超过任一虚构大制作,即撕掉「炮灰」标签
- **对手**:两部虚构大制作按固定排片策略发行,等你错峰超越

## 5 档结局

| 结局 | 条件 |
|---|---|
| 票房冠军 | 7 天总票房超过两部大制作 |
| 逆袭黑马 | 盈利且已翻转标签 |
| 勉强回本 | 盈利但未翻转 |
| 档期炮灰 | 小额亏损(亏损 < 2500 万) |
| 血本无归 | 大额亏损 |

## 运行

```bash
# 交互模式(需要终端)
python3 -m piaofang_nixi

# 自动演示:AI 贪心发行人连开 10 局
python3 -m piaofang_nixi --auto --games 10 --seed 42

# 自动演示 + 每日战报
python3 -m piaofang_nixi --auto --games 1 --seed 7 --verbose
```

纯 Python 标准库(`argparse`/`random`/`sys`),Python 3.10+。

## 诚实局限

- 数值为游戏性拍脑袋调参,不反映真实电影市场;分账/成本模型高度简化
- AI 发行人是固定规则贪心(前三天重营销、排片略激进),不是最优策略,也不是真人水平
- 事件纯随机 + 简单条件触发,无真实的口碑传播模型
- 票房冠军结局极难(需总票房超两部大制作),多数对局集中在「逆袭黑马/档期炮灰」
- 纯文本界面,无图形、无存档;倒计时等花活一概没有
